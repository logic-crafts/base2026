## Root architecture contract

Verified public evidence → source-linked original editorial packet → structural
validation + separate semantic/privacy review → exact-hash internal publishing
RPC → public editorial D1 → server-rendered blog/article/RSS/sitemap → reviewed
free distribution → native and attributable-site measurement.

Canonical hub `/blog`; new posts `/blog/<slug>/`; existing `/journal/*/` URLs
remain unchanged. New articles must not require a full site rebuild. Store
public structured content, never raw transcript/media/private research. Escape
all rendering; allow only validated public URLs; keep retry/idempotency/revision
conflicts explicit. Root owns transport authorization; a review hash alone is
not an authentication mechanism.

Instagram identity/profile links are discovery evidence, not proof of media
capture or permission. No login/CAPTCHA bypass, cookie export, stealth or paid
fallback. Real support requires an allowed acquisition plus downstream proof.
The existing cloud pipeline remains distinct from Codex/ChatGPT authoring;
do not label host-dependent authoring as cloud-only runtime.
