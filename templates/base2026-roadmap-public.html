Public roadmap

Build trust, then test the next useful layer.

This is a public sequence for making a narrow evidence corpus easier to find, verify, cite, correct and reuse. The current focus is free evidence search, repeatable research workflows and responsible learning from use.

Now

Free evidence search and tools

Improve the product, navigation, mobile experience, source explanations, attribution and correction paths. The complete public product runs on Cloudflare at base2026.dev.

Next

Repeatable professional workflows

Measure renewed research activity, review source support and test additional value with qualified users while keeping free public access and boundaries clear.

Exploring

Commercial integrations

Consider shared research and paid workflows only where recurring demand and responsible delivery support them. This path stays exploratory until repeated use provides evidence.

What is live

Cloudflare Workers serves the site, read-only API, forms, and public search. Public D1 with FTS5 powers the search workspace without a browser API key. Public source records, topic and creator pages, free tools, exports, APIs and correction routes make the evidence path inspectable.

Some processing stages still depend on review. Coverage, freshness and unresolved source questions remain visible.

Current delivery history

Earlier roadmap work established the public trust layer, searchable source records, topic and creator pages, read-only developer access, public exports and correction routes. The build journal, API guide, dataset and public release manifest retain the technical record as the product changes.

That history remains part of the project. The Now / Next / Exploring sequence above states the customer-facing priorities for the current stage.

How progress is judged

  • People return to complete another research task.
  • Sources remain attributable, useful and correctable.
  • Professional users can identify additional value without requiring recurring bespoke research.
  • Operating cost and editorial effort remain workable at the observed level of use.

What comes after evidence

Additional public source platforms, developer integrations and commercial experiments can be considered after the existing product shows repeated use. Any next layer must preserve free useful access, source attribution, correction rights and the public/private boundary.
