Clear boundaries

Free means usable, not magical.

No signup for current browser tools

The three public tools use small read-only public requests. They do not require a Base2026 account or browser API key.

No hidden private upload

Keep GSC exports, client context and unpublished work local. The public source path receives only deliberate, non-sensitive queries or IDs.

No ranking promise

Corpus counts and attributed creator passages can guide research. They do not prove traffic, consensus, effectiveness or a future position.

No automatic publication

The tools create a readout or handoff. Site edits, WordPress actions and external publication remain human-owned decisions.

FAQ

Before you choose a tool

Which tool should I start with?

Use Evidence Search when you have a question but no selected records. Use Source Diversity Check when you already have IDs and need to inspect relationships. Use Source-backed Brief when you want a portable local note. Use the SEO Experiment Planner for one existing page and a real content-refresh measurement question.

Are the browser tools really free?

There is no Base2026 signup or paywall for the three current public tools. Your compatible agent, provider plan or optional data service may have its own terms or costs; Base2026 does not fabricate keyword volume or rank forecasts.

Do the counters show users or live pipeline activity?

No. The counters are aggregate public dataset fields from /api/stats: documents, distinct sources, public evidence routes and projected cards. They are not visitor, video, user, job or backend-health metrics.

Can I send a private GSC export here?

No. Keep GSC rows and client details in your authorized local workflow. The open SEO skill can work in planning-only mode without a baseline and uses public retrieval only for deliberately selected non-sensitive research queries or IDs.
